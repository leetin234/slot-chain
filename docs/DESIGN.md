# SLOT CHAIN 디자인 기준

토스(TDS) 다크 테마의 원칙을 차량 화면(2560×1440, 160dpi, 1.3배 확대)에 맞춰 옮긴 기준입니다. 모든 화면은 `DesignSystem.kt`의 토큰과 컴포넌트만 사용합니다.

## 원칙

1. **한 화면 한 메시지** — 가장 중요한 숫자·문장을 가장 크게. 보조 정보는 회색으로 물러나게.
2. **선 대신 면** — 카드 테두리·그라데이션·발광을 쓰지 않는다. 배경과 카드의 명도 차이로만 구분한다.
3. **색은 의미가 있을 때만** — 파랑(주 행동·진행), 빨강(문제), 초록(완료), 주황(주의). 나머지는 모두 회색 단계.
4. **넉넉한 여백** — 카드 안 24, 카드 사이 16, 묶음 사이 32.
5. **누르면 반응** — 누를 수 있는 것은 모두 눌림 축소(0.97)와 스프링 복귀.

## 색 (다크)

| 토큰 | 값 | 용도 |
|---|---|---|
| `bg` | #17171C | 화면 배경 |
| `surface` | #202027 | 카드 |
| `surfaceHi` | #2C2C35 | 칩·입력·보조 버튼·토글 꺼짐 |
| `divider` | #2C2C35 | 목록 구분선(필요할 때만) |
| `text` | #ECECEF | 제목·값 |
| `text2` | #9E9EA6 | 설명·라벨 |
| `text3` | #6B6B76 | 캡션·비활성 |
| `blue` | #3182F6 | 주 행동·선택·진행 |
| `blueText` | #64A8FF | 어두운 배경 위 파란 글자 |
| `red` | #F04452 | 지각·만석·실패 |
| `green` | #15C47E | 완료·여유 |
| `orange` | #FFA826 | 주의·미확인 |
| `*Weak` | 해당 색 16% | 배지·상태 카드 배경 |

## 글자 (Pretendard, 자간 −0.3)

| 이름 | 크기 | 굵기 | 용도 |
|---|---|---|---|
| `display` | 64 | Bold | 핵심 시각·숫자 |
| `title1` | 34 | Bold | 화면 제목 |
| `title2` | 28 | Bold | 카드 제목·시설명 |
| `title3` | 23 | Bold | 상태 문장 |
| `body1` | 20 | SemiBold | 목록 값·버튼 |
| `body2` | 18 | Medium | 본문 |
| `caption` | 15 | Medium | 라벨·설명 |
| `small` | 13 | Medium | 출처·각주 |

## 모양

- 둥글기: 카드 24, 버튼·입력 16, 칩·배지 10, 알약 50%
- 그림자: 쓰지 않음(지도 위 떠 있는 요소만 아주 옅게)

## 컴포넌트

- **버튼**: Primary(파랑 채움·흰 글자), Secondary(surfaceHi·흰 글자), Weak(파랑 16%·파란 글자). 높이 64, 글자 `body1`.
- **토글**: 64×38 알약, 켜짐 파랑·꺼짐 surfaceHi, 흰 손잡이가 스프링으로 이동.
- **칩**: 선택 시 파랑 채움·흰 글자, 미선택 surfaceHi·회색 글자.
- **슬라이더**: 6dp 트랙(채움 파랑), 흰 원 손잡이, 단계 점 표시.
- **배지**: 색 16% 배경 + 같은 색 글자, `caption` Bold.
- **목록 행**: 왼쪽 `text2` 라벨, 오른쪽 `text` 값, 구분선 없음.
- **토스트**: 화면 위쪽 중앙 알약, surfaceHi 배경, 아이콘 + `body1`.

## 움직임

- 화면 전환: 페이드 + 짧은 수평 이동(320ms)
- 숫자 변경: 위로 밀려 올라가는 롤링(400ms)
- 상태 카드: 아래에서 떠오름(380ms)
- 진행 막대·차트: 0에서 차오름(900ms, 감속)
